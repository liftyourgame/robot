Robot Build Specification

A complete recipe for assembling the Humanising Technologies biped robot from 3D-printed parts, servos, and a Raspberry Pi.

What You're Building

A 50%-scale humanoid biped robot based on the Meshy AI character model. The robot has a full 23-bone skeleton, 18 degrees of freedom, and is controlled by a Raspberry Pi 5 running a servo driver board. All structural shell panels are 3D printed in PETG.

Before you start: Read through the entire spec first. Order all electronics and filament before printing — some lead times (especially Raspberry Pi) can be 1–2 weeks.

Build Stages

Stage 1 — Print all parts ~40h print time

22 STL files covering the full skeleton. Torso requires two separate print jobs.

Stage 2 — Heat-set inserts ~2h

Press M3 inserts into all joint mounting holes using a soldering iron.

Stage 3 — Skeleton assembly ~4h

Bolt the shell panels together from feet up. Dry-fit before final torque.

Stage 4 — Servo installation ~4h

Mount 18 servos into their brackets. Centre all servos before installation.

Stage 5 — Electronics & wiring ~6h

Install Raspberry Pi, PCA9685 boards, IMU, and route all servo cables.

Stage 6 — Power system ~2h

Wire the LiPo, voltage regulators, and power rails. Test voltages before connecting.

Stage 7 — Software & calibration ~3h

Flash Raspberry Pi OS, install servo libraries, run calibration script.

Safety note: LiPo batteries can be dangerous if punctured, overcharged, or short-circuited. Always use a balance charger, never leave charging unattended, and store in a fireproof bag.

3D Printing Guide

How to configure Bambu Studio and slice each part correctly.

Slicer Setup

1

Install Bambu Studio

brew install --cask bambu-studio

Or download from bambulab.com/en/software. Open the app and select your printer model.

2

Import an STL

Drag an STL from the specs/stl_parts/ folder onto the build plate, or use File → Import → Import 3MF/STL.

3

Set Scale to 50%

Select the model → in the right panel set Scale = 50% uniformly on all axes. The assembled robot will be 850mm tall.

4

Apply Print Settings

5

Torso Split — Important

The full torso at 50% scale is ~340mm, which exceeds the P1S build volume (256mm). Split into two print jobs:

  • Print job A: Spine02.stl (upper chest front + rear)
  • Print job B: Spine.stl + Spine01.stl + Hips.stl (mid + lower torso + pelvis)

Join the two sections with 3× M3 × 12mm bolts through heat-set inserts.

Test fit first: Print any part in PLA+ at 100% scale before committing to PETG. Check servo pocket sizes and bolt hole positions. PETG is harder to re-print if dimensions are off.

Skeleton Assembly

Build from the ground up — feet first, torso last. Dry-fit every joint before final tightening.

Before assembly: Install all heat-set inserts first (see step 1). Do not force bolts into bare plastic — always use inserts.
1

Install Heat-Set Inserts

Heat your soldering iron to ~230°C. Attach the heat-set insert tip. Press one M3 insert into each bolt hole across all printed parts. The insert should sit flush or 0.2mm below the surface.

  • ~6 inserts per shoulder cap (3 joint + 3 servo mount)
  • ~4 inserts per hip socket
  • ~4 inserts per knee bracket
  • ~2 inserts per ankle housing
  • ~6 inserts in torso join plates
Let each insert cool for 60s before moving the part. PETG remains soft for longer than PLA.
2

Assemble Feet

For each foot (left and right):

  1. Attach ToeBase to Foot shell with 2× M3 × 8mm bolts.
  2. Press one MR83ZZ bearing into the ankle pivot hole.
  3. Set aside — ankle servo installed in Stage 4.
3

Assemble Lower Legs

For each leg:

  1. Attach Foot assembly to Shin (LeftLeg/RightLeg) with the ankle hinge pin. Do not tighten fully — leave free to rotate.
  2. Attach Shin to Thigh (LeftUpLeg/RightUpLeg) with knee hinge pin housing. Press one bearing into each hinge hole.
4

Assemble Torso

  1. Join the two torso print sections: align Spine01 + Spine + Hips (print B) to Spine02 (print A).
  2. Insert 3× M3 × 12mm bolts through the join plates. Torque to finger-tight + ¼ turn.
  3. Attach Hip pelvis (Hips) to each Thigh via hip ball joint cups.
5

Assemble Arms

For each arm:

  1. Attach Hand to Forearm with 2× M3 × 8mm bolts.
  2. Attach Forearm to Upper Arm at elbow hinge pin.
  3. Attach Shoulder cap to Upper Arm with ball joint cup.
  4. Attach shoulder assembly to Spine02 (upper chest) with 3× M3 × 8mm.
6

Attach Head

  1. Press neck collar into top of Spine02 and bolt with 2× M3 × 8mm.
  2. Attach Head shell to neck collar. Leave the head-pan servo mount open for Stage 4.

Servo Installation

18 servos across 18 joints. Centre all servos before mounting.

Critical: Centre every servo (PWM pulse = 1500µs) before installing it. A servo installed off-centre will bind and strip gears on first power-up.

Centring Servos

Connect each servo to a servo tester or temporarily to the PCA9685 and send a 1500µs pulse. Mark the horn position with a permanent marker before removing it.

Two PCA9685 boards share the same I²C bus with different addresses. Set board 2 address by bridging the A0 solder pad to give it address 0x41 (board 1 default is 0x40).

Mounting Tips

  • Always attach the servo horn after the servo is seated in its bracket
  • Use M2 × 6mm bolts for servo horn attachment — servo horn screws are single-use, don't over-torque
  • Route servo cables through the channel grooves moulded into the shell panels
  • Secure cables with 3D-printed cable clips (S-06 from parts list) every ~50mm

Electronics & Wiring

All electronics mount inside the chest cavity on the electronics tray (S-07).

I²C Bus Wiring

The Raspberry Pi 5 communicates with both PCA9685 servo driver boards over I²C (SDA/SCL). A logic level converter is required because the Pi runs at 3.3V and the PCA9685 operates at 5V.

MPU-6050 IMU Wiring

MPU-6050 PinRaspberry Pi Pin
VCC3.3V (Pin 1)
GNDGND (Pin 6)
SDAGPIO 2 (Pin 3)
SCLGPIO 3 (Pin 5)
INTGPIO 17 (Pin 11) — optional
Do not connect servos to the Raspberry Pi directly. Servo power draw will brown-out the Pi. All servo power comes from the 6V regulated rail — only the PWM signal line connects through the PCA9685.

Assembly Order

1

Mount Electronics Tray

Screw the electronics tray (S-07) into the inside of Spine02 (upper chest) with 4× M3 × 8mm bolts through heat-set inserts.

2

Mount Raspberry Pi

Attach Pi 5 to tray with 4× M2.5 × 6mm standoffs + bolts. Ensure SD card slot faces downward for access.

3

Mount PCA9685 Boards

Mount both servo driver boards beside the Pi. Bridge A0 pad on board 2 to set address 0x41.

4

Wire I²C Bus

Use 22 AWG wire. Keep I²C runs under 300mm total. Twist SDA/SCL together to reduce interference.

5

Connect Servo Signal Lines

Connect each servo's signal (orange/yellow) wire to the corresponding PCA9685 channel per the servo map. Ground wires (brown/black) connect to the PCA9685 GND rail.

Cable routing: Run mic cables down through the neck channel and into the chest cavity alongside the servo signal harness. Use cable management clips (S-06) to keep them tidy. Keep I²S wire runs under 200 mm total to avoid signal degradation.

Ear Panel Cutout

Each ear panel (part of the Head Shell) requires a 12 mm diameter hole centred on the inner face to seat the INMP441 module. Use a drill press or rotary tool after printing. The module snaps in and is held with a dab of hot glue.

Software Setup

1

Enable I²S overlay

sudo nano /boot/config.txt
# Add these lines:
dtparam=i2s=on
dtoverlay=googlevoicehat-soundcard

Reboot after saving. The googlevoicehat-soundcard overlay works with both the MAX98357A and INMP441.

2

Test microphone input

# Record 5 seconds from left mic
arecord -D plughw:0 -c2 -r 16000 -f S32_LE -d 5 test.wav
aplay test.wav
3

Test speaker output

# Play a test tone
speaker-test -t wav -c 1
# Or play a file
aplay -D plughw:1 your_audio.wav
4

Install Python audio libraries

pip3 install pyaudio SpeechRecognition pyttsx3
# Optional: OpenAI Whisper for on-device speech recognition
pip3 install openai-whisper

Use SpeechRecognition for voice commands and pyttsx3 for text-to-speech through the chest speaker.

Power System

Two separate regulated voltage rails from a single 3S LiPo.

LiPo Safety Rules: Never discharge below 3.0V per cell (9.0V total). Never charge above 4.2V per cell (12.6V total). Always charge in a fireproof bag. Never leave charging unattended.

Power Architecture

Wiring Steps

1

Set Regulator Output Voltages

Before connecting anything else, power each regulator from a bench supply and trim the output potentiometer to exactly 6.0V (servos) and 5.1V (Pi). Verify with a multimeter.

2

Connect Servo Power Rail

Run 18 AWG wire from the 6V regulator output to the PCA9685 V+ rail. This powers all servo motors. Do NOT connect this to the Pi.

3

Connect Pi Power

Connect the 5V regulator to the Pi's USB-C power port using a USB-C PD cable, or solder directly to the 5V GPIO pins (Pin 2 + Pin 6).

4

Final Check Before First Power-On

  • Measure voltage at servo rail: must be 6.0V ± 0.1V
  • Measure voltage at Pi rail: must be 5.0–5.2V
  • Check for short circuits with multimeter continuity mode on GND/V+ before connecting LiPo
  • Connect LiPo — Pi should boot, all servos should be quiet (no signal yet)

Software Setup

Flash Raspberry Pi OS, enable I²C, install servo libraries, and run the calibration script.

1

Flash Raspberry Pi OS

Download Raspberry Pi Imager from raspberrypi.com. Flash Raspberry Pi OS Lite (64-bit) to the 32GB SD card. Pre-configure WiFi and SSH in the imager settings.

2

Enable I²C

sudo raspi-config
# Interface Options → I2C → Enable
sudo reboot

After reboot, verify both PCA9685 boards are detected:

sudo i2cdetect -y 1
# Should show 0x40 and 0x41
3

Install Libraries

pip install adafruit-circuitpython-pca9685 \
            adafruit-circuitpython-servokit \
            mpu6050-raspberrypi
4

Run Servo Calibration

This script sweeps each servo through its range and confirms correct channel mapping:

from adafruit_servokit import ServoKit

kit1 = ServoKit(channels=16, address=0x40)
kit2 = ServoKit(channels=16, address=0x41)

# Sweep all servos to centre
for i in range(16):
    kit1.servo[i].angle = 90
    kit2.servo[i].angle = 90

print("All servos centred")
5

Read IMU

from mpu6050 import mpu6050
sensor = mpu6050(0x68)
accel = sensor.get_accel_data()
gyro  = sensor.get_gyro_data()
print("Accel:", accel)
print("Gyro:", gyro)

Verify the IMU returns sensible values. Z-axis acceleration should be ~9.8 m/s² when the robot is upright.
